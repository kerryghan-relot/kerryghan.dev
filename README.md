# Portfolio

Hello, this is the code to my personnal portfolio.

It is now still under construction and it will be improved overtime.

## Installation

Simply clone the repository and launch the `index.html` file.

In order to make the form submission work, you'll need the Web3Forms public key set up.
To do so, create a file named `env.js` and put the following content in it:
```js
const WEB3FORMS_KEY = "<your_public_key_goes_here>";
```
